# VenciApp — Documentos legales

Este repositorio aloja los documentos legales públicos de **VenciApp**, la
aplicación móvil para el control de vencimientos tributarios en Colombia.

Se sirve estáticamente vía GitHub Pages para cumplir con los requisitos de
publicación de Apple App Store y Google Play Store, que exigen una URL pública
estable para la política de privacidad.

## Documentos

- `privacy-policy.md` — Política de Privacidad (Ley 1581 de 2012, Decreto 1377
  de 2013).
